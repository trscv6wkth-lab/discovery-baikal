# Дискавери Байкал

Многостраничный учебный сайт о природе и путешествии к Байкалу. В проекте 7 связанных страниц, адаптивная верстка, авторские SVG-иллюстрации, видео, контакты, ссылка на Google Maps и форма отзывов с backend на Google Apps Script.

## Страницы

- `index.html` — главная;
- `about.html` — о Байкале;
- `routes.html` — идеи маршрутов;
- `gallery.html` — авторские иллюстрации;
- `video.html` — 360° видео AirPano VR;
- `reviews.html` — форма и лента отзывов;
- `contacts.html` — e-mail и карта.

## Публикация сайта на GitHub Pages

1. Создай публичный репозиторий GitHub с названием `discovery-baikal`.
2. Загрузи **содержимое** этой папки в корень репозитория.
3. Открой **Settings → Pages**.
4. В блоке **Build and deployment** выбери **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажми **Save**.
5. Подожди, пока GitHub Pages покажет ссылку вида `https://<логин>.github.io/discovery-baikal/`.

## Подключение отзывов через Google Apps Script

1. Открой [script.google.com](https://script.google.com/) под своим Google-аккаунтом и создай новый проект.
2. Скопируй содержимое `google-apps-script/Code.gs` в редактор Apps Script и сохрани.
3. Нажми **Deploy → New deployment → Web app**.
4. В поле **Execute as** выбери **Me**, в **Who has access** — **Anyone**, затем нажми **Deploy** и подтверди разрешения Google.
5. Скопируй адрес развернутого Web App, заканчивающийся на `/exec`.
6. Открой `assets/reviews.js` и замени пустое значение `REVIEWS_API_URL` на этот адрес, сохрани изменения и обнови файлы в GitHub.
7. Проверяй отзывы в созданной автоматически таблице «Дискавери Байкал — отзывы» на Google Drive.

При первом POST-запросе Apps Script создаст таблицу и лист «Отзывы». Важно: настройка **Anyone** позволяет посетителям отправлять публичные отзывы; каждый отправленный текст хранится в твоей Google-таблице и показывается на сайте.
